Layout canvases — how to see the VISUAL preview

================================================



IMPORTANT: npm open scripts do NOT work here. The `cursor` CLI on your machine

opens your WORK Cursor, not this private one.



Also: double-clicking a .canvas.tsx file always shows SOURCE CODE. That is normal.

Cursor does not have a markdown-style Preview button for canvases yet.



Do this IN YOUR PRIVATE CURSOR (this window, Private workspace):



1. Open workspace file (once):

   File → Open Workspace from File → Private/Private.code-workspace

   You should see a sidebar folder "Layout canvases (rendered preview)".



2. Open the rendered canvas (pick ONE):

   A) Ctrl+Shift+P → type "Open Canvas" → choose

      deep-cousin-column-scenario.canvas.tsx

      join-deep-cousin-scenario.canvas.tsx

      wide-four-gen-pedigree-scenario.canvas.tsx

      w3g-layout-pipeline.canvas.tsx
      jdc-layout-pipeline.canvas.tsx
      regression-family-layout-pipeline.canvas.tsx

      (This is the most reliable method.)



   B) In the "Layout canvases" folder: RIGHT-CLICK the file → Open

      (Do NOT double-click — that opens raw TSX.)



3. Use Editor / IDE layout, not Agents-only layout.

   Canvas preview is not available in Agents-only view.



Canvas files live at:

  family-roots/canvases/   (default export target)

  Or set CURSOR_CANVASES_DIR to your Cursor workspace canvases folder.



Refresh after layout engine changes:

  cd family-roots && npm run export:layout-canvas

Large regression-family pipeline (from anonymized backup JSON):

  cd family-roots && npm run export:regression-family-canvas
  (defaults to test-data/regression-family-backup.json)
